# Madden NFL 05 PS2 — Default Playbooks

Reference documentation for the default playbooks available in Madden NFL 05 for PlayStation 2.

## Overview

Madden 05 PS2 ships with 32 NFL team playbooks (one per team from the 2004 NFL season). Each playbook includes:
- ~75 built-in plays (limited by the game's max custom playbook cap of 75 total plays)
- Formation assignments specific to that coach/team's philosophy
- Pre-designed audible packages

## Notable Playbooks

### Bill Belichick — New England Patriots (2004)

**Philosophy**: West Coast / Pro-Style balanced
**Signature plays**:
- Mesh timing routes
- Inside Zone runs
- Power-O gap scheme

**Known plays in library compatible**: Mesh, Snag, Inside-Zone, Power, Play-Action Cross

### Bill Parcells — Dallas Cowboys (2004)

**Philosophy**: Power-Run / Pro-Style
**Signature plays**:
- Gap-blocking runs (Power, Counter)
- Play-action deep shots
- Screen passes

**Known plays in library compatible**: Power, Counter-Trey, PA-Cross, Bubble Screen

### Tony Dungy — Indianapolis Colts (2004)

**Philosophy**: Spread-Option / West Coast hybrid
**Signature plays**:
- Zone runs
- Spacing routes
- Read-option (early form)

**Known plays in library compatible**: Inside-Zone, Outside-Zone, Mesh, Drag routes

### Marty Schottenheimer — San Diego Chargers (2004)

**Philosophy**: Power-Run
**Signature plays**:
- Outside-zone stretches
- Lead-blocking runs
- Play-action bootlegs

**Known plays in library compatible**: Outside-Zone, Lead-Toss, PA-Bootleg

### Mike Holmgren — Seattle Seahawks (2004)

**Philosophy**: West Coast
**Signature plays**:
- Short-intermediate timing routes
- Zone runs off play-action
- Three-level progressions

**Known plays in library compatible**: Mesh, Flood, Inside-Zone, Play-Action
